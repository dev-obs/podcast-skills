# Dev’Obs — Dans le rétro

Work in the requested episode folder. Preserve the raw material and keep a private record of existing projects and drafts so work can resume on another machine. Follow the requested scope. A request through the draft includes Auphonic processing when authorized. Treat publishing and scheduling as separate requests.

1. **Identify the recording and resume.** Match existing drafts and productions before creating new ones. When numbering or delivering an episode, use the shared Dev’Obs sequence in Transistor. Read the [episode and draft workflow](references/release.md).
2. **Edit the aligned stems.** Recover Craig’s synchronized tracks or use the supplied stems. Confirm the first intended greeting and last words, preview both cut edges, and apply the same interval to every speaker. Read [source recovery and editing](references/editing.md), including the local FFmpeg fallback.
3. **Process the stems.** Use the existing Auphonic multitrack preset, which is still named **Dev’Obs — Dans ton rétro**. Verify track processing, metadata, and delivery destinations before starting one authorized run. Read [Auphonic postproduction](references/auphonic.md).
4. **Prepare the release assets.** Use the processed master and its VTT. Review the opening again after automatic cuts. Correct the French transcript, preserve cue timing and speaker labels, and place chapters on the processed timeline. Follow the verification steps in the [episode and draft workflow](references/release.md).
5. **Verify the Transistor draft when requested.** Match the recording, upload the final MP3, and verify the draft, chapters, and timed transcript. Use the dashboard if the connector lacks local file upload. Report the artifacts, available draft link, and any listening or dashboard checks still pending.

Use live connector schemas when available. Prefer the signed-in provider dashboard when a connector cannot take local files or is unavailable. Continue independent work if one integration is blocked.
